# zkFMI brand

Concept: delivery versus payment. Two legs, cash (amber) and securities
(periwinkle), interlock and move together; the value they settle is a sealed
commitment (teal hexagon) in the overlap, never opened.

- `zkfmi-lockup-{dark,light}.svg` — horizontal lockup, 480x160, with background
- `zkfmi-lockup-{dark,light}-transparent.svg` — same, no background
- `zkfmi-mark-{dark,light}.svg` — square mark, 128x128, with background
- `zkfmi-mark-transparent-{dark,light}.svg` — square mark, no background
- `zkfmi-og.svg` — 1200x630 social card source (rendered to `static/og.png`)
- `../static/favicon.svg` — simplified mark for 16–32 px

Palette: ink #e8eef4 / #0e1622, teal #5ee0c1 / #0c8c73, amber #f2b880 / #b0611a,
periwinkle #9bb0ff / #3f56c9, background #0a0e13 / #fbfcfd (dark / light).
Wordmark: "zk" in JetBrains Mono 600, "FMI" in Inter 800.

Earlier candidates are kept in `candidates/`.
